# Todo App

A modern, responsive Todo web application built with React, Vite, and CSS.

## Features
- **Task Management**: Add, toggle complete, and delete tasks.
- **Filter Views**: Easily toggle between All, Active, and Completed tasks.
- **Persistent Storage**: Saves your tasks in `localStorage` so they stay when you refresh.
- **Modular Component Architecture**: Organized with clean, focused sub-components.
- **Automated Deployment**: GitHub Actions workflow deploying automatically to GitHub Pages.

## Getting Started Locally

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```
